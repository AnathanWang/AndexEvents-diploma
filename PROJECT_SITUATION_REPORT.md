# Отчет о состоянии проекта Andex Events
**Дата:** 12 февраля 2026

## 1. Общий обзор архитектуры
Проект находится в стадии активной миграции с монолитного Node.js бэкенда на гибридную микросервисную архитектуру (Java Spring Boot + Go).

### Текущий архитектурный паттерн: **Hybrid Microservices**
- **Точка входа:** Traefik (Reverse Proxy & API Gateway) на порту `80`.
- **Маршрутизация:** Все запросы `/api/*` маршрутизируются на соответствующие контейнеры.
- **База данных:** Единый PostgreSQL кластер с установленным расширением PostGIS.

---

## 2. Статус Бэкенда (Infrastructure & Services)

### Инфраструктура (Docker)
Запускается через: `deployments/docker/docker-compose.hybrid.yml`

| Сервис | Технология | Порт (Внешний/Внутренний) | Статус | Описание |
|--------|------------|---------------------------|--------|----------|
| **Traefik** | Go (Image) | `80:80`, `8080:8080` | 🟢 Активен | API Gateway, дашборд |
| **Postgres** | PostgreSQL 16 | `5432:5432` | 🟢 Активен | Основная БД + PostGIS |
| **MinIO** | Object Storage | `9000:9000` | 🟢 Активен | S3-совместимое хранилище (аватары, фото) |
| **Redis** | In-memory DB | `6379:6379` | 🟢 Активен | Кэширование, сессии |

### Микросервисы

| Сервис | Язык / Фреймворк | Порт | Роут (API) | Описание |
|--------|------------------|------|------------|----------|
| **Users** | Java (Spring Boot)| `8081` | `/api/users` | Управление профилями |
| **Events** | Java (Spring Boot)| `8082` | `/api/events` | Создание и поиск событий |
| **Auth** | Java (Spring Boot)| `8083` | `/api/auth` | Авторизация (Firebase интеграция) |
| **Match** | Go (Golang) | `8005` | `/api/matches` | Логика совпадений/лайков |
| **Upload** | Go (Golang) | `8006` | `/api/upload` | Загрузка медиа в MinIO |

> **Примечание:** Старый Node.js бэкенд выведен из эксплуатации и перемещен в архив.
